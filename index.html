아크릴 케이스 목업 사용 설명서

판(파츠)마다 이미지를 넣고, 돌리고 움직여서 입체로 조립해 보는 도구입니다.

1. 시작하기

  • 열면 앞·뒤·좌·우·상·하 판과 내부파재가 단색 판으로 조립된 상태로 나옵니다. 기본 크기는 가로 100 × 세로 71 × 깊이 52mm, 두께 3mm입니다.
  • 화면을 드래그하면 시점이 회전하고, 스크롤하면 확대·축소, 우클릭(또는 두 손가락) 드래그는 이동입니다.
  • "기본 배치로 초기화"를 누르면 처음 상태로 돌아갑니다(내가 한 수정은 사라집니다).

2. 파츠 선택과 이름

  • 사이드 패널 목록의 이름을 누르거나 화면에서 판을 클릭하면 선택됩니다. 목록 옆 체크박스는 표시/숨기기입니다(위·앞 판을 숨겨 안쪽을 볼 때 편합니다).
  • "선택한 파츠" 아래 입력칸에서 이름을 바꿀 수 있고, 복제·삭제 버튼도 있습니다.

3. 이미지 넣기

  • 앞면 이미지 교체 / 뒷면 이미지 넣기: 양면 아크릴이면 앞·뒤 이미지를 따로 넣습니다. 뒷면은 판을 뒤에서 봤을 때 보이는 모습 그대로 만들면 됩니다. "시점 앞↔뒤"로 카메라를 반대편으로 옮길 수 있습니다.
  • 이미지 해상도(DPI): 넣은 이미지의 픽셀 수를 DPI로 환산해 파츠 크기가 정해집니다(기본 300). DPI는 이미지를 넣기 전에 맞추세요.
  • 여백 자동 제거: 이미지 가장자리의 투명한 빈 공간을 잘라냅니다. 모서리 색 투명은 배경이 단색인 이미지의 배경색을 지울 때 켭니다(판 자체가 흰색이면 판까지 지워질 수 있어 기본은 꺼져 있습니다).
  • 새 파츠는 "＋ 이미지로 파츠 추가"로 만듭니다. 여러 장을 한꺼번에 고를 수 있고, 파일명에 앞/뒤/좌/우/상/밑(바닥)과 내부/외부가 들어 있으면 판 역할과 안·바깥면을 자동 인식해 박스로 조립합니다(예: 밑판내부, 우판외부). 같은 판의 내부·외부 이미지는 한 파츠의 뒷면·앞면으로 합쳐집니다. 조립면(탭·홈)이 있는 이미지는 오브젝트 영역 기준으로 바깥면이 맞도록 배치되며, "자동 조립" 버튼으로 언제든 다시 맞출 수 있습니다.
  • 스탠드 "꽂는 부분"은 이미지 여백이 아니라 실제 그림 영역의 아래쪽 끝(바닥면)에 생깁니다.

4. 움직이고 맞추기

  • 선택하면 나타나는 조절 도구를 끌어 이동/회전합니다("이동"·"회전" 버튼으로 전환). 위치(mm)·회전(°)·크기(mm)는 숫자로도 입력할 수 있고, X/Y/Z +90° 버튼으로 바로 돌립니다.
  • 핸들 기준: 기본은 파츠 방향(로컬)이라 화살표가 판의 가로·세로·두께 방향을 그대로 따릅니다. 필요하면 "화면 고정(월드)"로 바꿀 수 있습니다.
  • 파츠 스냅: 이동 중 다른 파츠의 면·모서리·중심선·단차선(탭 가장자리 등 윤곽이 꺾이는 선)에 지정 거리 안으로 다가가면 자석처럼 붙고 색 면으로 표시됩니다. 두께 방향으로는 딱 맞닿는 위치에 붙습니다.
  • 스냅을 켜면(이동 0.5/1/5mm, 회전 15/45/90°) 끌 때 일정한 간격으로만 움직여 딱 맞추기 쉽습니다.
  • 겹침 검사: 판끼리 겹치면 붉게 표시되고 목록에 ⚠가 붙습니다. "겹침 해소"는 선택 판을 두께 방향으로 밀어 겹침이 없는 가장 가까운 위치에 둡니다.
  • 숫자칸 드래그: 숫자칸 위에서 좌우로 끌면 값이 바뀝니다(Shift 10배, Alt 0.1배). Ctrl+Z로 되돌리기, Ctrl+Shift+Z(또는 Ctrl+Y)로 다시 실행합니다.
  • 꽂는 부분: 꽂는 면(위·아래·왼쪽·오른쪽)과 위치 미세조정을 정할 수 있고, "구멍 자동 생성"은 꽂는 부분이 닿은 판에 맞는 구멍을 뚫어 줍니다.
  • 분해 ↔ 조립 슬라이더로 판을 바깥으로 펼쳐 볼 수 있습니다(분해 중에는 이동 도구와 겹침 검사가 꺼집니다).

5. 재질과 두께

  • 재질: 투명 / 반투명(프로스트) / 불투명 화이트 / 스모크. "인쇄 외 바탕 불투명도"는 흰색에 가까운 부분이 얼마나 비칠지, "광택"은 반짝임 정도입니다.
  • 흰 잉크(파츠마다 앞면/뒷면 따로): "있음"은 흰색 계열도 만화처럼 꽉 차고, "없음"은 흰 부분이 투명하게 비칩니다.
  • 아크릴 두께(1~10mm)는 전체 판에 공통으로 적용되고 판 단면이 두께만큼 보입니다. 두께를 바꾼 뒤에 판 위치는 자동으로 다시 계산되지 않으니 직접 맞추거나 초기화하세요.

6. 칼선과 흰 테두리

  • "칼선 표시"를 켜면 판의 외곡과 구멍 둘레에 분홍색 칼선이 그려집니다.
  • "흰 테두리"는 선택한 파츠(주로 아크릴 스탠드)의 그림 외곡에 흰 테두리(칼선 여유)를 0~10px로 추가합니다.

7. 아크릴 스탠드 꽂는 부분과 구멍

  • 꽂는 부분: 스탠드로 쓸 파츠를 선택하고 "꽂는 부분 만들기"를 켜면 아래쪽 가운데에 탭이 붙습니다(폭·길이 mm 입력). 탭 두께는 아크릴 두께와 같습니다.
  • 구멍: 바닥판 등을 선택하고 "구멍 뚫기"를 켜고 "＋ 추가"로 여러 개를 만듭니다. 구멍마다 위치 X/Y(판 중심 기준, mm), 가로/세로, 회전각을 정합니다.
  • 스탠드 위치로 구멍 맞추기: 스탠드를 먼저 원하는 자리에 둔 뒤 누르면 선택한 구멍이 탭이 지나는 자리로 옮겨집니다.
  • 구멍 = 꽂는 부분 + 공차: 켜면 모든 구멍의 가로는 탭 폭, 세로는 아크릴 두께에 공차(기본 0.1mm)를 더한 값으로 자동 설정되고 입력칸이 잠깁니다.

8. 이미지 저장

  • 선택 파츠 저장: 구멍·꽂는 부분이 반영된 판을 투명 배경 PNG로 저장합니다(뒷면이 있으면 앞·뒤 두 장을 zip으로). 전체 파츠 저장은 모든 판을 zip 하나로 묶습니다. 칼선 표시가 켜져 있으면 칼선도 함께 그려집니다.
  • 현재 화면 저장(PNG): 지금 보이는 3D 화면을 저장합니다(조절 도구는 자동으로 숨겨집니다).
  • 저장할 때 확인창이 뜨며 허용해야 파일이 저장됩니다.
알아두세요
  • 이 화면은 미리보기용 근사치입니다. 겹침 검사는 이미지의 실제 불투명 영역(윤곽·단차·구멍 포함)과 판 두께를 기준으로 하며, 겹침 허용오차(기본 0.2mm) 이하로 닿거나 꽉 끼는 것은 겹침으로 보지 않습니다.
  • 구멍은 직사각형만 가능하고, 최종 제작 전에는 실제 도면으로 다시 확인하세요.
