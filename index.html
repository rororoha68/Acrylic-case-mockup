아크릴판 배치

새 창에서 판 크기를 정하고 파츠를 실제 크기 그대로 배치한 뒤 PNG로 내보냅니다. 자동 배치는 파츠 간격 3mm 이상.

저장

「보기」의 칼선 표시를 켜면 분홍색 칼선이 이미지에 함께 그려집니다.

사용 설명서

판(파츠)마다 이미지를 넣고, 돌리고 움직여서 입체로 조립해 보는 도구입니다.

  • 열면 견본 프리셋이 나옵니다. 앞·뒤·좌·우·상·하 판은 면마다 다른 단색, 안쪽의 내부파츠 1·2는 주황색 영역으로만 표시됩니다. 크기는 앞·뒤 62.1×43.9, 좌·우 31.2×49.7, 상·하 62.1×31.2mm, 두께 3mm입니다.
  • 앞판의 투명 창은 안쪽 파츠가 보이는 자리, 판 가장자리의 작은 홈과 좌·우 판의 돌출부는 판끼리 끼우는 자리, 하판의 긴 구멍 2개는 내부파츠의 꽂는 부분이 들어가는 자리입니다.
  • 순서: ① 판을 클릭해 선택 → ② 「앞면 이미지 교체」로 내 그림 넣기 → ③ 내부파츠도 같은 방법으로 그림 넣기(크기는 그림에 맞게 바뀝니다). 색만 바꾸고 싶으면 「단색 면 색상」을 쓰세요.
  • 화면 빈 곳을 드래그하면 시점이 회전하고, 스크롤하면 확대·축소, 우클릭(또는 두 손가락) 드래그는 화면 이동입니다.
  • 판을 클릭하면 선택되고, 선택된 판에는 이동/회전 화살표가 나타납니다.
  • 숫자칸 드래그: 숫자칸 위에서 좌우로 끌면 값이 바뀝니다(Shift 10배, Alt 0.1배).
  • Ctrl+Z로 되돌리기, Ctrl+Shift+Z(또는 Ctrl+Y)로 다시 실행합니다.

누른 방향에서 케이스를 바라보도록 시점을 즉시 옮깁니다. 예를 들어 앞은 앞판 바깥면이 정면으로 보이는 시점, 상은 위에서 내려다보는 시점입니다.

  • 현재 확대 정도와 화면 이동 상태는 유지되고 방향만 바뀝니다.
  • 상·하 시점에서는 앞쪽이 화면 아래(상) 또는 위(하)에 놓입니다.
  • 누른 뒤에도 드래그로 자유롭게 돌릴 수 있습니다.

처음 열었을 때의 비스듬한 3D 시점과 확대 정도로 되돌립니다(화면 이동도 초기화).

3D 화면 뒤에 단색 배경을 깝니다. 끄면 배경이 투명하게 처리되어 화면 테마 색이 보입니다.

  • 체크박스: 배경색을 켜고 끕니다.
  • 색 칸: 원하는 색을 직접 고릅니다(고르면 자동으로 켜집니다).
  • 흰색 · 회색 · 검정 · 녹색: 자주 쓰는 색을 한 번에 적용합니다. 녹색은 나중에 배경을 지우기 쉬운 크로마키용입니다.
  • 켠 상태에서 「현재 화면 저장(PNG)」을 누르면 배경색이 그대로 이미지에 포함되고, 꺼 두면 투명 배경 PNG로 저장됩니다.
  • 프로젝트 저장/자동 저장에도 함께 기록됩니다.

슬라이더로 판을 바깥으로 펼쳐 안쪽 구조를 볼 수 있습니다. 분해 중에는 이동 도구와 겹침 검사가 꺼집니다.

판의 외곽과 구멍 둘레에 분홍색 칼선을 그립니다. 켜 둔 채로 파츠 이미지를 저장하면 칼선도 이미지에 함께 그려집니다.

지금 보이는 3D 화면을 PNG로 저장합니다. 조절 도구(화살표)는 자동으로 숨겨지고, 「배경색 깔기」가 켜져 있으면 배경색이 포함됩니다.

이름을 누르거나 화면에서 판을 클릭하면 선택됩니다. 이름 옆 체크박스는 표시/숨기기입니다(위·앞 판을 숨겨 안쪽을 볼 때 편합니다). 겹친 판은 이름 앞에 ⚠가 붙습니다.

이미지 파일로 새 파츠를 만듭니다. 여러 장을 한꺼번에 고를 수 있습니다.

  • 파일명에 앞/뒤/좌/우/상/밑(바닥)과 내부/외부가 들어 있으면 판 역할과 안·바깥면을 자동 인식해 박스로 조립합니다(예: 밑판내부, 우판외부).
  • 같은 판의 내부·외부 이미지는 한 파츠의 뒷면·앞면으로 합쳐집니다.
  • 조립면(탭·홈)이 있는 이미지는 오브젝트 영역 기준으로 바깥면이 맞게 배치됩니다.

선택한 파츠를 색 칸에서 고른 한 가지 색으로 칠합니다(색을 끌면 바로 반영). 투명한 창·홈 모양은 유지됩니다.

  • 전체 파츠에 이 색: 모든 파츠를 같은 색으로 칠합니다.
  • 견본 색으로 되돌리기: 면마다 다른 처음 색으로 되돌립니다.
  • 그림을 넣은 파츠에 쓰면 그림이 단색으로 덮이니 주의하세요(Ctrl+Z로 되돌릴 수 있습니다).

처음 상태의 견본 프리셋(단색 판 + 내부파츠 영역)으로 돌립니다. 내가 한 수정은 사라지므로 필요하면 먼저 프로젝트를 저장하세요(Ctrl+Z로도 되돌릴 수 있습니다).

파츠 이름(앞·뒤·좌·우·상·밑)을 기준으로 전체를 박스 모양으로 다시 맞춥니다. 분해 상태에서는 동작하지 않습니다.

넣은 이미지의 픽셀 수를 DPI로 환산해 파츠 크기를 정합니다(기본 300). 이미지를 넣기 전에 맞추세요.

  • 여백 자동 제거: 이미지 가장자리의 투명한 빈 공간을 잘라냅니다.
  • 모서리 색 투명: 배경이 단색인 이미지의 배경색을 지울 때 켭니다. 판 자체가 흰색이면 판까지 지워질 수 있어 기본은 꺼져 있습니다.

둘 다 이미지를 새로 넣을 때 적용됩니다.

선택한 파츠의 이름을 바꿉니다. 자동 조립은 이 이름의 앞·뒤·좌·우·상·밑을 보고 판 역할을 정합니다.

선택하면 나타나는 조절 도구의 모드를 바꿉니다. 화살표를 끌어 이동하거나 고리를 끌어 회전합니다. 맞춤 도구의 스냅 설정이 여기에 적용됩니다.

선택한 판의 앞면 이미지를 다른 파일로 바꿉니다. 크기는 DPI 설정에 따라 다시 계산됩니다.

  • 뒷면 이미지 넣기: 양면 아크릴이면 뒷면 이미지를 따로 넣습니다. 판을 뒤에서 봤을 때 보이는 모습 그대로 만들면 됩니다.
  • 뒷면 제거: 넣은 뒷면 이미지를 지웁니다.
  • 뒷면은 「보기」의 뒤 시점 등으로 반대편에서 확인하세요.

가로/세로를 mm로 입력합니다. 비율 고정이 켜져 있으면 한쪽을 바꿀 때 다른 쪽이 원본 비율로 따라옵니다. 아래의 「오브젝트 영역」은 스냅·겹침 검사가 쓰는 실제 그림 영역 크기입니다.

위치(mm)와 회전(°)을 숫자로 직접 입력합니다. X/Y/Z +90° 버튼은 해당 축으로 90°씩 바로 돌립니다.

파츠마다 앞면/뒷면을 따로 정합니다. 있음은 흰색 계열도 꽉 차게, 없음은 흰 부분이 투명하게 비치게 보여 줍니다. 재질 따름은 재질 설정의 불투명도를 따릅니다.

선택한 파츠의 그림 외곽에서 바깥쪽으로 칼선을 얼마나 띄울지 mm로 정합니다. 그림과 칼선 사이는 투명 영역으로 남습니다.

  • 전체 설정 따름: 「아크릴 칼선」의 기본값(처음 2mm)을 그대로 씁니다. 기본값을 바꾸면 이 파츠도 같이 바뀝니다.
  • 직접 지정: 슬라이더로 0.1~10mm 사이에서 이 파츠만 따로 정합니다.
  • 없음: 이 파츠는 칼선을 만들지 않고 그림 모양 그대로 둡니다.
  • 꽂는 부분과 구멍은 칼선 바깥에서 붙고 뚫리므로 입력한 mm 크기 그대로 유지됩니다.
  • 케이스 판(앞·뒤·좌·우·상·하)과 처음 견본의 내부파츠는 조립 치수가 어긋나지 않도록 「없음」으로 시작합니다. 새로 추가한 파츠는 「전체 설정 따름」으로 시작합니다.
  • 복제: 이미지·구멍·꽂는 부분까지 그대로 복사해 옆에 놓습니다.
  • 삭제: 선택한 파츠를 지웁니다.

스탠드로 쓸 파츠를 선택하고 체크하면 그림 영역의 끝에 탭이 붙습니다. 탭 두께는 아크릴 두께와 같습니다.

그림 실루엣이 탭 위치까지 닿지 않아 사이가 떨어져 있으면, 그 사이(밑부분)를 탭 폭만큼 자동으로 메워 그림과 탭이 한 덩어리로 이어지게 만듭니다(메운 부분과 탭은 인쇄 없이 투명 아크릴로 남고, 모양·칼선에는 포함됩니다).

  • 폭/길이: 탭의 크기(mm)입니다.
  • 꽂는 면: 아래(바닥)·위·왼쪽·오른쪽 중 탭이 붙는 쪽입니다.
  • 위치 미세조정: 탭을 가운데에서 좌우(또는 상하)로 옮깁니다.

스탠드를 바닥판 위 원하는 자리에 둔 뒤 스탠드를 선택하고 누르면, 탭이 닿은 판에 위치·각도·크기(탭 폭 × 두께 + 공차)가 맞는 구멍을 만들어 줍니다. 같은 자리(1.5mm 이내)에 이미 구멍이 있으면 그 구멍을 맞춰 줍니다. 조립 상태에서만 동작합니다.

바닥판 등을 선택하고 구멍 뚫기를 켠 뒤 ＋ 추가로 여러 개를 만듭니다. 목록에서 구멍을 고르고 − 삭제로 지웁니다. 구멍은 직사각형만 가능합니다.

구멍마다 위치 X/Y(판 중심 기준, mm), 가로/세로, 회전각을 정합니다.

켜면 모든 구멍의 가로는 탭 폭, 세로는 아크릴 두께에 공차(기본 0.1mm)를 더한 값으로 자동 설정되고 크기 입력칸이 잠깁니다.

조절 도구로 끌 때 일정한 간격으로만 움직이게 합니다(이동 0.5/1/5mm, 회전 15/45/90°). 기본 회전 스냅은 90°입니다.

파츠 방향(로컬)은 화살표가 판의 가로·세로·두께 방향을 그대로 따르고, 화면 고정(월드)은 화면 기준 X/Y/Z로 고정됩니다.

이동 중 다른 파츠의 면·모서리·단차선(탭 가장자리 등 윤곽이 꺾이는 선)에 지정 거리 안으로 다가가면 자석처럼 붙고 색 면으로 표시됩니다. 두께 방향은 딱 맞닿는 위치에 붙습니다. 중심선도 맞춤을 켜면 중심선에도 붙습니다.

판끼리 겹치면 붉게 표시하고 목록에 ⚠를 붙입니다. 이미지의 실제 불투명 영역(윤곽·단차·구멍 포함)과 판 두께를 기준으로 하며, 허용오차(기본 0.2mm) 이하로 닿거나 꽉 끼는 것은 겹침으로 보지 않습니다.

선택한 판을 두께 방향으로 밀어 겹침이 없는 가장 가까운 위치(최대 10mm)에 둡니다.

투명 / 반투명(프로스트) / 불투명 화이트 / 스모크 중에서 고릅니다. 고르면 바탕 불투명도도 그에 맞게 바뀝니다.

  • 바탕 불투명도: 흰색에 가까운 부분이 얼마나 비칠지 정합니다.
  • 광택: 낮을수록 반짝입니다.

1~10mm. 전체 판에 공통으로 적용되고 판 단면이 두께만큼 보입니다. 두께를 바꿔도 판 위치는 자동으로 다시 계산되지 않으니 직접 맞추거나 초기화하세요.

그림의 외곽선에서 바깥쪽으로 일정 간격(mm)을 띄운 둥근 칼선을 자동으로 만듭니다. 칼선 안쪽 빈 곳은 투명 영역으로 남습니다(저장 PNG에서도 투명).

  • 칼선 자동 생성: 「전체 설정 따름」인 파츠에 칼선을 만들지 켜고 끕니다.
  • 기본 칼선 여유(mm): 기본값은 2mm이고 0~10mm 사이에서 0.1mm 단위로 조절합니다.
  • 파츠별로 다르게 하려면 파츠를 선택하고 「칼선 여유 (이 파츠)」를 바꾸세요.
  • 칼선은 「보기」의 칼선 표시를 켜면 분홍색 선으로 보이고, 파츠 저장 PNG에도 같은 모양으로 반영됩니다.

아크릴판 한 장 위에 모든 파츠를 실제 크기 그대로 놓아 보고 내보내는 화면입니다. 「🧩 아크릴판에 파츠 배치하기」를 누르면 새 창이 열립니다(브라우저가 팝업을 막으면 현재 화면 위에 겹쳐서 열립니다). 확대·축소는 보기만 바뀔 뿐 파츠 크기는 변하지 않습니다.

  • 판 크기(mm): 가로×세로를 직접 입력하거나 목록에서 고릅니다. 가장자리 여백 안쪽(점선)에만 놓는 것이 기준입니다.
  • 자동 배치: 파츠 사이를 간격(최소 3mm) 이상 띄워 빈틈없이 채워 놓습니다. 「90° 회전 허용」을 켜면 더 촘촘히 놓을 수 있습니다. 파츠는 사각형 영역(꽂는 부분 포함) 기준으로 배치됩니다. 판이 작아 못 들어간 파츠는 판 오른쪽 밖에 둡니다. 처음 열 때는 자동으로 한 번 배치됩니다.
  • 마음대로 옮기기: 파츠를 끌어서 옮기고, 선택 후 X/Y(mm)를 입력하거나 방향키(Shift 5mm · Alt 0.1mm)로 미세 이동합니다. R 또는 「90° 회전」으로 돌립니다.
  • 간격만큼 자석 붙이기: 끄는 동안 다른 파츠·판 가장자리에 간격을 두고 붙습니다(Alt를 누르면 일시 해제).
  • 간격이 모자라거나 겹치거나 여백 밖인 파츠는 붉은 테두리로 표시되고, 아래 안내줄에 개수가 나옵니다. 손으로 옮길 때는 막지 않고 경고만 합니다.
  • 빈 곳을 끌면 화면 이동, 스크롤(또는 두 손가락)로 확대·축소, Ctrl+Z / Ctrl+Y로 배치를 되돌리거나 다시 합니다.
  • 배치 PNG 내보내기: 판 크기 그대로(지정 DPI) 투명 배경 PNG로 저장합니다. 파일에 DPI 정보가 들어 있어 일러스트레이터·포토샵 등에서 실제 크기(mm)로 열립니다. 「칼선 표시」가 켜져 있으면 칼선도 그려집니다. 앞면 이미지 기준이며, 판 밖에 있는 파츠는 저장되지 않습니다.
  • 메인 변경 반영: 배치 창을 연 채 메인 창에서 파츠를 고쳤다면 이 버튼으로 새 모양을 불러옵니다. 이미 놓은 위치는 유지되고 새 파츠만 빈 곳에 놓입니다.
  • 📄 참고용 PDF: 1쪽 안내문 → 판 배치(아트워크) → 파츠별 페이지 순서로 한 파일에 담아 저장합니다. 칼선 여유가 지정된 파츠는 아트워크 페이지 바로 다음 장에 벡터 칼선 페이지가 따로 붙고, 칼선이 하나라도 있으면 판 배치 칼선 페이지도 들어갑니다. 모든 페이지는 실제 크기(1:1)입니다. 참고용 파일이므로 일러스트레이터 등에서 열어 수정한 뒤 사용하세요(아트워크는 비트맵, 칼선만 벡터이며 안내문·페이지 제목은 이미지입니다).
  • 배치는 프로젝트 저장·자동 저장에 함께 기록됩니다.
  • 선택 파츠 저장: 구멍·꽂는 부분이 반영된 판을 투명 배경 PNG로 저장합니다(뒷면이 있으면 앞·뒤 두 장을 zip으로).
  • 전체 파츠 저장(zip): 모든 판을 zip 하나로 묶습니다.
  • 칼선 표시가 켜져 있으면 칼선도 함께 그려집니다.

모든 파츠(이미지 포함)·위치·회전·구멍·꽂는 부분·재질·배경색 등을 .json 파일 하나로 저장합니다. 외부 백업이므로 클라우드·USB 등에 보관하세요. 불러오기로 그대로 복원됩니다.
